# 标准参考实现

这里描述现有“占占四流一致索引中心（AI直做）”的业务语义和成熟视图经验。它是客户部署时的参考答案，不是要求所有客户使用相同表名和字段名的硬编码结构。

标准模型分四层：

1. 文件索引：一行代表可独立定位的原始或派生文件对象。
2. 专业集合：一行代表合同、回单、发票、货物流等专业对象。
3. 业务事实：一行代表去重后的流水、履约或项目事实。
4. 审核结果：一行代表合同付款节点或四流关系的审核对象。

`base-manifest.example.yaml` 提供公开的脱敏语义清单。客户真实 token、table_id、field_id、人员和数据不得提交到公共仓库。
