# 法人主体与交易对象身份识别

公司名称不能作为法人唯一键。证据优先级依次为：统一社会信用代码、纳税人识别号、历史登记号、银行账号及户名、法定全称、工商或税务更名材料、发票、合同、已确认别名、来源上下文。

同一信用代码对应新旧名称时使用同一法人键，保留标准名称、原文名称、历史名称、简称、银行户名和 OCR 原文。没有权威材料时不得猜测更名日期。

集团、子公司、分公司、关联公司、最终用户、采购人和付款人可能是不同主体，不得因名称相似或来源群相同自动合并。第三方代收代付必须有合同、授权、三方协议或其他强证据。

身份硬冲突包括同名不同代码、同代码出现无解释的不相关名称、合同与发票税号冲突、流水账号属于另一法人、映射与原件主体冲突、印章与正文主体冲突。发生冲突时保留全部原始值并提交人工确认。

工具可以规范文本、校验代码、精确检索账号和生成影响范围；只有 Agent 能判断更名、简称、集团关系、第三方安排及主体合并或拆分。禁止按名称相似度自动合并法人。
