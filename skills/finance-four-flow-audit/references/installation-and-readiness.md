# Aily 安装与真实环境验收

## 安装边界

读取 Skill 不等于能力已部署。分别证明：规则可召回、飞书权限可用、智能体电脑可执行脚本、工具依赖可安装、群事件可触发、原件可下载、对象库可上传、Base 可受控写入、群内可回执。

智能体电脑属于平台沙箱，不假设仓库、依赖或本地文件跨任务永久保存。每次任务先发现能力；需要持久部署的确定性工具应使用 Aily MCP、自定义连接器或经实测稳定的沙箱执行方式。

## 只读验收

按真实 API 返回记录并核验：

1. 监听群的真实 chat_id、群名、消息/文件/图片/伴随文字/引用读取能力。
2. 每群对象库 token、递归读取、下载和上传权限。
3. Base token、真实表名/table_id、字段/选项/关联/公式、视图筛选排序分组显隐填色。
4. Wiki 空间和节点权限。
5. 自动化触发器、唯一消费者、断线补扫、checkpoint、通知对象。
6. 智能体电脑的系统、Python、Git、网络、依赖和文件输出能力。
7. 回单切割命令和测试；真实原件切割后逐页视觉检查预览。

只读阶段禁止写 Base、上传移动删除云盘文件或处理历史全量。所有 ID 和数量必须来自 fresh API，不使用占位符、整理名或旧报告推断。

## 单文件演练

选择一个授权文件，完成证据包、归档、原件视觉阅读、分类、候选检索和动作清单但不写业务表。客户确认后执行一次受控写入：写前 fresh-read/快照、有界写入、写后 fresh-read、业务验证、幂等复跑、群内回执和回滚定位。

## 上线判定

能力状态使用 `PASS / PARTIAL / MISSING / UNKNOWN`：

- PASS：真实样本端到端完成且有证据。
- PARTIAL：局部成功，但未覆盖真实样本、关键边界或持久性。
- MISSING：环境明确不提供。
- UNKNOWN：未能取得证据。

存在任意写入保护、原件获取、工具执行、断线补扫或通知缺口时为 NOT READY。上线需记录批准人、时间、配置哈希、Skill版本、工具版本和回滚方法。
