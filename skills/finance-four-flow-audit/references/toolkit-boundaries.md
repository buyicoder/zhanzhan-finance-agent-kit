# Agent 固定工具箱与调用边界

## 案件上下文

案件开始先读取来源群、消息 ID、时间、文件/图片/伴随文字、多附件、回复引用、对象库、Base、Schema 版本、处理阶段和 checkpoint。

## 确定性工具

- 群历史、消息资源和引用关系；
- 云盘列举、递归、下载、上传和元数据；
- 文件物化、SHA-256、临时空间清理和证据登记；
- PDF 元数据、渲染、文本辅助、切割、裁剪和验证；
- Office 全部非空 sheet/页检查与渲染；
- 压缩包安全解包；
- 二维码解码；
- Base Schema、字段、视图、记录和候选检索；
- 信用代码校验、历史名称和跨表影响检索；
- 金额池、时间窗、比例和汇总计算；
- 动作清单、受控写入、fresh-read、快照、幂等、回滚和 checkpoint。

## 权限边界

工具只负责机械操作和候选召回。文件分类、业务事实、重复归并、主体身份、关系置信度和审核结论必须由 Agent 判断。

PDF 文本不能替代关键页视觉阅读；切割工具不能自行判断回单边界；候选索引不能直接建立关系；二维码解码不能宣称已核验发票；名称相似度不能自动合并法人；API 成功不能替代写后验证。

## 回单切割工具

Skill 内置 `scripts/receipt_split.py`。调用前，Agent 必须完成原件全部页面视觉检查，并按 [receipts.md](receipts.md) 给出每张回单的页码与归一化区域。工具支持同页多回单和单回单跨页，负责：

- 校验原文件 SHA-256 与切割计划；
- 原子生成派生 PDF 和逐页 PNG 预览；
- 校验输出可打开、页数正确、渲染非空；
- 返回父对象、来源哈希、计划哈希、派生哈希和幂等键；
- 同计划复跑只复用通过完整性校验的结果，计划变化时拒绝覆盖。

工具不会上传云盘、写 Base、判断回单语义或自动采用机器检测边界。Agent 视觉判断完成后调用示例：

```bash
python3 scripts/receipt_split.py source.pdf plan.json output-directory
```

节省成本应发生在精确检索、缓存、结构预览和确定性计算上，不能省略原件视觉核验。
